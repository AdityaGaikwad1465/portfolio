## 🚀 Visual Features & Engineering Interactive Modules

- **⚡ HTML5 PCB Circuit Canvas Engine**: Real-time particle stream along orthogonal PCB trace lines with interactive cursor magnetic pull effect.
- **📟 Live Interactive Oscilloscope Simulator**: Simulated signal generator rendering Sine Wave, Square Wave, Triangle Wave, and PWM Pulse signals with real-time Frequency and Voltage Amplitude sliders.
- **🖥️ Hardware CLI Terminal Console**: Interactive terminal allowing visitors to type commands (`skills`, `education`, `lab-exp`, `contact`, `clear`, `help`) or click quick action buttons.
- **🔊 Web Audio API Sound Synthesizer**: Optional cyber sound effects toggle when interacting with buttons, knobs, and terminal commands.
- **🎓 Interactive Education Timeline**: Glowing vertical PCB node timeline covering Anantrao Pawar College of Engineering & Research (Pune), Milind Junior College (Latur), and Shri Deshikendra School.
- **📱 Fully Responsive Cyber Neon HUD**: Dark mode aesthetic optimized for mobile, tablet, and widescreen displays.
